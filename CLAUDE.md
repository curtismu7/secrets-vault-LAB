# secrets-vault-LAB

Demo-tier standalone app: Ping User Vault and Secret Store Management release claims (deck slides 42 and 43, with slides 36 and 35 read only; release 2026-11-02). A per-user credential vault (strictly self-service, no administrator override, real AES-256-GCM, injected at request time by a simulated gateway so the backend logs who actually acted, merge-edit, staged delete purged after 24 hours, 500 entries and 64 KB bounds) and secret store management over five mock providers (AWS, GCP, Azure, Delinea, CyberArk: separate read and write grants, audit, nightly re-sync, metadata only with the value fetched live and never stored). Simulated. **Every product claim is "Ping release claim, UNVERIFIED on our tenant"** (banner on every tab, presenter mode too).

- Run: `./scripts/run.sh` (http://localhost:7450). Test: `npm test` (server is `node --test test/*.test.js`, a glob; web is vitest against the real Express app; scripts). Preflight `npm run doctor`. Reset `npm run reset`. Docker: `HOST_PORT=7450 docker compose up --build -d`. Node 26 only.
- Refusals are real 4xx statuses (no refusalsAs200 flag), audited credential-free; one normaliser (NFKC, default-ignorable, Cf and every C0/C1 control except tab/LF/CR DELETED, UTF-8 percent-decoding up to four rounds, then a second look with the separators deleted) serves the cleaner, the name tests, the hop panes and the response mask (object keys included); a missing file is a JSON 404 (the page shell answers only extension-less non-dotfile GETs), a wrong method on a known route is a 405 with Allow, a credential-looking workspace id is a 400 bad_workspace (the page regenerates its id and retries once); the proof is a window-index generator, time-sliced on demand, cached by state version; a workspace holds at most 4 MB of sealed credentials; lab helpers (provider change, manual re-sync) are admin-only.
- Modes: **Mock** (default) = tables (`server/src/mockTable.json`, generated by `npm run mock-table` from seven scripted scenarios run through the engine with a deterministic random source; a doctor check and a test fail on drift; read-only, every write is 409). **Live** = the real engine on the visitor's own actions, as the person chosen in the header (`X-Lab-Actor`, a lab stand-in for the verified token). Both loopback-only, zero outbound (netguard + a test).
- Core: `engine.js` (vault, gateway call, targets, key restart, secret stores, grants, audit, re-sync, no-copy proof, lab clock; one Engine per workspace and vertical), `crypto.js` (AES-256-GCM, AAD = user id + entry id, the three mock key providers), `gateway.js` (the simulated backend and the injected header shapes), `stores.js` (five mock providers with real state), `policy.js` (read and write grants, a segment matcher with no regex), `actions.js` (the one dispatch used by the API, the scenarios and the tests), `scenarios.js` (+ Mock table builder), `credentials.js` + `mask.js`, `service.js`, `app.js`. Web: `useLab` hook, six tabs.
- Rules that bite: **no value is ever returned by any API** (vault entries show present, size, version, masked; store reads are delivered to a simulated consumer and the answer says "value delivered to the consumer (masked)"; the provider connection credentials are sealed at rest and never shown); **no call takes an owner**: the caller (X-Lab-Actor, validated against the roster, the role taken from the roster) is the only vault there is, another person's entry id is "not found", an `owner` in a query, body or call is refused with 400; fixed refusal messages must never look like a credential (the response mask would eat them: no "secret is", "token:" and the like, a test checks every message); typed names, paths, tags and header names that look like credentials are refused, notes are masked; every user value used as an object key is type-checked; unknown body keys and query parameters are refused without naming them; the clock only moves forward; purge at exactly 24 h (now >= stagedAt + 24 h); the proof search is bounded on writes in a large workspace and says SKIPPED, never a made-up pass; Mock scenario results use a deterministic RNG only for the tables; ports 7450-7499; UI: shared `web/src/styles/standalone-ui.css` vendored byte-for-byte, app CSS tokens only (`bash ~/Development/AI-DEMO-Standalone/scripts/check-css.sh .`).
- Tags: every field is "deck claim", "lab reading" or "lab-invented" (data.js FIELD_SOURCES); this lab cites no console swagger names. Provider call shapes are illustrations on `.example` hosts, never sent.
- Settings: one shared file `~/Development/.env` (mode 600, `STANDALONE_ENV` overrides), parsed with `util.parseEnv` in `server/src/settings.js`; this lab takes only `SVL_LAB_MODE`, never a bare MODE.
- Run check-drift, check-css and conformance by hand. SE k8s build deferred (owner, 2026-10-31); no k8s manifests. Catalog id D108 (planned in PROPOSED-CATALOG-ROWS-PRIVILEGE-DECK-2026-10-31.md).
